iRPGFormatter Plug-in

Hi, this is the home of the iRPGFormatter plug-in for IBM Rational Developer for i.

 Version: 2.2.0.r

Introduction

iRPGFormatter is an open source plug-in for IBM Rational Developer for i. It formats free-form RPG IV source code to improve readability and consistency.

iRPGFormatter features are driven from our ideas and needs, but everybody is encouraged to contribute suggestions and manpower to improve the power of iRPGFormatter.

The iRPGFormatter Project Team


Tools/400, Thomas Raddatz

Features

  • Indents the calculations by the nesting of their blocks and the comment lines like the following statement.
  • Formats embedded SQL statements according to the RDi preferences page Free-form SQL Formatting.
  • Formats the branches of conditional compiling (/IF, /ELSE, /ENDIF) like the compiler.
  • Various formatting options, e.g. the casing style, adding or removing the keyword const(), replacing the name of dcl-pi with *N and removing the name of end-proc.
  • Optionally formats the calculations with the IBM formatter.
  • Formats the whole source or the selected lines in the LPEX editor. A selection is expanded to the whole block.
  • Formats many sources at once from the Remote Systems view or the Project Explorer.
  • Optionally formats a source on save.
  • Project specific settings, e.g. for the sources of a Git repository, that the team formats the same way.
  • Lists the problems in the view iRPGFormatter Problems and in the ruler of the editor.
  • Lets AI agents like Claude Code format sources with the settings of RDi: the optional feature iRPGFormatter iAgentBridge adds the tool format_rpg to the MCP server of the plug-in iAgentBridge.

Installation

The easiest way to install the iRPGFormatter plug-in is using Eclipse Marketplace. Search for iRPGFormatter:

Eclipse Marketplace

But you can also use the official update site at GitHub:

IBM Rational Developer for i - RDi 9.6.0.13+
Last but not least you can download the local update site as a zip file and install iRPGFormatter from there:

GitHub Files

The optional feature iRPGFormatter iAgentBridge requires the plug-in iAgentBridge. Install iAgentBridge first. iRPGFormatter itself does not need it.
